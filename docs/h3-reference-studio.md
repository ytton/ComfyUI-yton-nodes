# H3 参考视频工作台

在 `yton-nodes / MiniMax H3` 中添加节点。左侧设置提示词、画幅、参考图尺寸和时长，右侧加载参考媒体，顶部右侧连接后续采样节点。

新建时参考图片、视频和音频全部展开；提示词框自动补齐两侧高度，节点随内容撑开，不出现内部滚动条。

面板、控件和媒体区域跟随节点原生背景与文字颜色，切换配色后即时更新；节点背景色随工作流保存。

- 连接文本编码器；使用图片或视频参考时连接视频 VAE，使用音频参考时连接音频 VAE。未加载素材时可以文生视频。
- 支持 9 张图片、3 段视频和 3 段音频，复用媒体加载器的上传、拖动交换、预览和禁用操作。图片完整等比显示，禁用素材保留原引用编号。
- 提示词可使用 `<Picture 1>`、`<Video 1>`、`<Audio 1>` 引用对应素材，也可将提示词转为输入端口连线。
- 输出分辨率沿用原分辨率控件的九档预设和括号内 H3 倍率，例如 `1080p (2.0)`。画面比例使用示意图卡片；自动比例取第一张启用图片，下方显示实际宽高。
- 参考图尺寸提供 `max`、`match` 和自定义。自定义以 match 结果为基础缩放宽高，遵循官方参考图尺寸上限；点击自定义或直接输入倍率即可启用。
- 时长一行显示 5 秒、10 秒、15 秒及自定义输入，支持 `7.91` 等小数秒，保留输入精度。按 24 fps、H3 的 `17n + 5` 帧向上对齐，并显示实际帧数与秒数。例如 7.91 秒输出 192 帧，即 8 秒。
- 参考图倍率和时长的自定义选项直接使用输入框，未选中时显示“自定义”，点击即可输入。

顶部右侧输出正向条件、AV latent、宽度和高度。节点不执行采样，继续使用工作流中的模型、采样器和解码节点；时长区域显示实际帧数。

## H3 视频生成配置器

`H3 视频生成配置器` 将常用的视频生成配置独立提供。左侧设置分辨率、比例、参考图尺寸和时长，右侧编辑提示词；图片、视频、音频列表与 `LLM 通用连接器` 使用节点连线接入。比例选“自动”时，按第一张连接图片计算；没有图片时使用 16:9。

点击提示词右上角的“优化”后，下一次执行会把原提示词、图片、视频均匀抽取的画面、视频音轨及独立音频交给已连接的 LLM。生成的提示词会成为节点的提示词输出，并回写到编辑框。优化不会在点击时单独发起 API 请求。

节点输出提示词、H3 对齐后的宽高、帧数与实际时长、参考图尺寸模式与倍率，以及图片、视频和音频列表。选择参考图尺寸“自定义”时，节点按倍率缩放图片并将尺寸模式输出为 `max`；图片列表、视频列表和音频列表可继续连接到下游 H3 生成节点。
