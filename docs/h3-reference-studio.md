# H3 参考视频工作台

在 `yton-nodes / MiniMax H3` 中添加节点。左侧设置提示词、画幅、参考图尺寸和时长，中间加载参考媒体，右侧连接后续采样节点。

- 连接文本编码器；使用图片或视频参考时连接视频 VAE，使用音频参考时连接音频 VAE。未加载素材时可以文生视频。
- 支持 9 张图片、3 段视频和 3 段音频，复用媒体加载器的上传、拖动交换、预览和禁用操作。图片完整等比显示，禁用素材保留原引用编号。
- 提示词可使用 `<Picture 1>`、`<Video 1>`、`<Audio 1>` 引用对应素材，也可将提示词转为输入端口连线。
- 分辨率显示当前比例下的实际 MP；自动比例取第一张启用图片。自定义分辨率按 32 像素对齐。
- 参考图尺寸提供 `max`、`match` 和自定义。自定义以 match 结果为基础缩放宽高，遵循官方参考图尺寸上限；点击自定义或直接输入倍率即可启用。
- 时长支持预设及直接输入小数秒。按 24 fps、H3 的 `17n + 5` 帧向上对齐，并显示实际帧数与秒数。例如 7.5 秒输出 192 帧，即 8 秒。

输出为正向条件、AV latent、宽度、高度和帧数。节点不执行采样，继续使用工作流中的模型、采样器和解码节点。
