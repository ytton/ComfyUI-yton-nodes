# H3 双采流：传统采样对照配置

[工作流](../examples/H3双采流-传统.json)以本机同名流程最近一次成功运行的配置为基础。保留参考素材、提示词、模型与编码器、0.7 首采比例和原来的上下文关闭状态。

| 阶段 | 配置 |
| --- | --- |
| 首采模型 | 当前基础模型 + DMAD dareties v4 LoRA 1.0 + 人物替换 LoRA 1.0 |
| 首采 | LCM、simple、6 步、denoise 1，Video/Audio Shift 12/3 |
| latent 放大 | h3_upscaler_lms_v0.1，按目标尺寸放大 |
| 二采模型 | 从模型桥接节点的 MODEL 输出明确连接，使用未叠加上述 LoRA 的基础模型 |
| 二采 | Euler，6 步，Sigma `0.4, 0.3, 0.2, 0.12, 0.06, 0.02, 0` |
| 修脸 | 暂时关闭，保留原有参数便于后续单独对照 |
| 种子 | 保留最近成功运行的种子，生成后固定 |

首采配置参考当前 DMAD 合并版本[作者说明](https://civitai.com/models/2837571)：6–8 步、er_sde/LCM、simple、强度 1.0、Video/Audio Shift 12/3。该建议属于此 LoRA，不是所有 H3 模型的统一推荐。

二采属于待实片检验的保守起点：从原有基础模型配两步 SA Solver、起点 0.6316，改为确定性的 Euler 和较低起点，给细化更多步数并减少重新改写画面的力度。填写 Sigma 后，以时间表间隔数决定实际步数；面板上的二采步数只在 Sigma 留空时生成自动曲线。

先以相同素材和种子观察人物轮廓；确定整幅画面正常后，再单独开启修脸。最终成片的重影也可能来自首采、参考视频中的运动模糊或修脸叠加，需要按阶段对照，不能仅凭调整 Sigma 保证消失。

已验证工作流载入、序列化、参数和模型连线。未提交 GPU 成片测试；二采由两次模型计算增加到六次，耗时会增加。
