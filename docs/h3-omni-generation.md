# H3 全模态生成

每次生成一个片段，并保存下一段需要的上下文。宽度和高度始终表示最终输出分辨率。

示例工作流：[H3 全模态生成 · 单采二采 · 分段修脸](../examples/H3_全模态生成_单采二采_分段修脸.json)。使用 1029 工作流的采样与模型配置，按模型配置、参考素材、H3 生成、输出分组，通过 Set/Get 连接共享模型、提示词和 Sigma。修改节点代码后重启 ComfyUI，再刷新页面并载入示例。

## 1029 分段配置

| 项目 | 示例设置 |
| --- | --- |
| 分辨率 | 节点宽 1920、高 1088、首采比例 0.5；自动以 960×544 首采、1920×1088 二采 |
| 主采样 | Euler、simple、4 步、denoise 1 |
| 二采 | sa_solver，Sigma `0.631578922, 0.3158, 0` |
| 修脸 | er_sde，Sigma `0.615, 0`，种子 42，大小脸倍率均为 1 |
| 生成 LoRA | character_swap v1.1 + LightX2V turbo 4step，两者强度均为 1 |
| 修脸 LoRA | 独立基础模型只加载 LightX2V turbo 4step，强度 1 |
| 文本编码器 | qwen3vl_32b_minimax_h3_nvfp4_awq |
| 成片放大 | RTX Video Super Resolution，1.5 倍、ULTRA |

分辨率只在生成节点设置宽、高和首采比例。比例分别乘到宽和高，结果按 32 像素对齐；0.5 对应宽高各减半、像素总量为四分之一。主采和二采共用同一个随机种子。主模型保留视频／音频 shift 12／3、Sol-attn τ 1.3、注意力分块 4、前馈分块 2。后续独立 RTX 放大节点的 1.5 倍作用于二采画面。

源视频可以直接完整接入 `H3 全模态生成` 的视频槽位。普通模式会在节点内部按“片段序号、时长、上一段上下文”计算起始帧：第 N 段从 `(N−1)×可见帧−22` 开始，自动取出本段源画面和音频；采样长度自动补足 22 帧上下文及 H3 的 `5+17×N` 帧格。解码后节点内部一次性裁去上下文和尾部对齐帧，所以填写 10 秒就得到 10 秒左右的可见成片，不需要外部裁剪、算帧或裁 22 帧。首段没有上一段上下文时不加重叠。更换源视频时使用新的上下文目录并从序号 1 开始。

复刻模式直接接入已经准备好的当前段视频，节点读取第一个视频的实际时长，自动计算 H3 采样长度；有上一段上下文时同样补 22 帧，输出端自动裁去上下文和帧格补齐部分。复刻模式不会再次把输入视频拆成外部流程。

人物参考图由素材节点的图片槽位提供。二采与修脸的 ManualSigmas 都实际接入采样器，示例不再放置源视频裁剪、帧数计算、音频裁剪或 22 帧裁切节点。

## 单采与二采

- **单采**：直接在目标分辨率执行主采样。
- **二采**：按“首采宽高比例”低分辨率采样，使用 H3 3D latent 放大模型升到目标尺寸，再执行独立的第二次采样。默认首采比例 0.625，二采使用 `sa_solver` 与 `0.631578922, 0.3158, 0.0` 时间表。
- 主采样 Sigma 和二采 Sigma 分开输入，接线后分别替代各自的时间表。
- 主模型使用 FastUse 的模型加载器，因为它同时提供模型、CLIP、视频 VAE 和音频 VAE。二采模型、修脸模型只需要直接接入 `MODEL`，可以接基础模型或已经串好多个 LoRA 的模型；未接时使用主模型。

普通模式按填写时长生成；复刻模式按当前输入视频的实际时长生成。两种模式都由节点内部处理上下文补齐和最终裁切。

## 分段接续

第一段使用序号 1。第二段起使用同一个上下文目录与递增序号；也可以填写“指定上一段上下文”，直接选择已采用候选返回的上下文文件，创建新的生成分支。

需要同时保留多个候选时，为每个候选设置不同的保存目录，再把采用候选的“本段上下文路径”填入后一段。相同目录与序号的再次生成会覆盖该上下文文件。

上下文采用 1029 工作流中的 `MiniMaxH3LatentHeadReplace`：从上一段尾部提取 22 帧对应的 7 个 latent 时间位置，写入新段头部，头部噪声遮罩为 0、后续区域为 1。二采会分别在主采样和放大采样前执行一次，使用各自分辨率的状态。整条接续链应保持目标分辨率和首采比例一致。

一个 safetensors 文件保存主采样状态、二采状态（单采不重复存储）以及最终显示画面的最后 4 帧。接缝处理使用这 4 帧作为亮度参考，生成结果只输出本段新画面。修脸后的画面用于接缝参考，采样 latent 保留修脸前状态，与原工作流的两路语义一致。

上下文文件写在 ComfyUI `output` 目录内，每次成功产出视频后原子替换当前片段文件。重抽上一段时，文件变化会使下一段的节点缓存失效。该文件同时包含两次采样所需的状态，不能只用最终输出的 AV latent 代替它。

## 小脸修复

开启后逐人执行：追踪裁切 → 768 上限的自适应局部画布 → 视频 latent 注入 → 按人脸大小调节降噪 → 局部采样 → 羽化贴回。默认修复 1 人，4 步、降噪 0.4，检测模型 `bbox\face_yolov8m.pt`。

大脸降噪倍率默认 35%，可以独立调整；示例按照 1029 设为 1。接入修脸 Sigma 后，修脸调度步数与降噪控件停用，所有人物使用输入的时间表。修脸使用独立种子，人体兜底检测模型也可设置。参考人物图片与提示词沿用生成输入。支持多人物依次修复及倒序修脸，最终恢复正常时间顺序。修脸仅替换画面，最终音频沿用整段生成结果。

关闭修复时不建立修脸子图，也不加载人脸检测或修脸采样资源。节点内复用安装的 `ComfyUI-H3-FaceRefine`；二采复用 `Comfyui_Minimax_h3_latent_Upscaler`，接续和接缝处理复用 `ComfyUI-MiniMax-Tools`。
