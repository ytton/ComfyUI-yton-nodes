# 提示词优化器

节点位置：**yton-nodes → 提示词 → 提示词优化器**。

## 输入与操作

- **启用提示词增强**：关闭后直接输出用户提示词，保留原文与空白；不读取 Skill、不处理媒体内容、不读取模型配置、不发送 API 请求。开启后按下方配置增强。
- **用户提示词**：可填写文字，也可连接 STRING 输出。连接后以连线内容为准。
- **系统提示词**：可编辑节点内的规则，也可连接 STRING 输出；留空时不发送系统提示词。
- **Skill**：从下拉框选择要使用的 Skill，或选择“不使用 Skill”。点击旁边的刷新图标重新扫描插件 `skills` 目录。执行时先读取 `SKILL.md`，再附上目录内文本参考文件，将完整文件包与系统提示词一起发送。
- **image · 图片列表**：直接连接媒体加载器的 `image` 输出，支持原生 IMAGE 列表与图片批次。
- **audio · 音频列表**：直接连接媒体加载器的 `audio` 输出，按 WAV 编码发送原生 AUDIO 列表。
- **video · 视频列表**：直接连接媒体加载器的 `video` 输出。每个视频均匀抽取最多 12 帧，附上时间位置；有原音轨时一并发送。

系统提示词、用户提示词或 Skill 至少提供一项，纯空白视为空。Skill 作为系统上下文，也可配合参考素材运行。

## 多文件 Skill

目录中的 Markdown、TXT、JSON、YAML、TOML、CSV、XML、HTML、模板和常见源码文件按相对路径分节，全部放入同一次模型请求。文件需为 UTF-8 编码；隐藏文件、环境目录、依赖缓存和二进制素材不纳入文本包。源码作为参考文本读取。图片、音频和视频素材仍使用对应媒体输入。

每次执行重新读取目录，修改参考文件后无需重建节点。最多 64 个文本文件，总量最多 512 KiB，超限时直接提示精简，避免截断规则。文件包仍需符合所选模型的上下文容量。

节点通过一次文本 API 请求使用 Skill 的创作规则，系统协议会说明运行环境并要求直接输出最终提示词。Skill 中的文件写入和脚本步骤作为参考，节点不执行脚本。模型返回工具调用或 DSML 调用标记时直接报错，避免将工具指令送入下游生图节点。

插件自带 MiniMax H3、Qwen Image 2.1 等提示词规则，刷新下拉框后可选择。添加自己的 Skill 时，把完整文件夹放在插件的 `skills` 目录中，每个文件夹根部需有 `SKILL.md`。例如：

```text
ComfyUI/custom_nodes/ComfyUI-yton-nodes/skills/你的Skill/SKILL.md
```

图片发送前将最长边限制在 1536 像素。模型需要支持输入所用的媒体类型；纯文本模型无法理解图片或音频。视频使用带时间标记的图片序列和音轨进行理解。

将“优化后的提示词”STRING 输出连接到下游文本输入。开启增强时，工作流执行到本节点便读取用户提示词、系统提示词和参考素材，调用所选模型的 API，再把返回文本输出给下游。开启增强的每次执行都会请求模型；节点只显示简短执行状态，需要查看正文时连接文本预览节点。

`examples/Moss生图.json` 使用 `moss-image-prompt-enhancer`，系统提示词明确选用自然语言 Caption 交付。增强器顶部的“启用提示词增强”可切换增强和原文直通，输出沿原有预览节点送入正向文本编码器。

右下角齿轮配置共享服务商、OpenAI 兼容地址、API Key 和模型。密钥仅保存在 ComfyUI 用户目录，不写入工作流。

本地 GGUF 推理使用同分类中的 [llama.cpp 提示词优化器](LLAMA_PROMPT_OPTIMIZER.md)，高级设置随各节点保存。

更新 Python 文件后重启 ComfyUI，再用 Ctrl+F5 刷新页面。重新添加节点可使用完整的默认输入端口。
