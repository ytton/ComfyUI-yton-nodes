# 本地模型显存联动

在 ComfyUI 设置的 **yton-nodes → 本地模型联动** 开启“执行工作流前卸载本地模型”，填写启动器根地址（默认 `http://127.0.0.1:8080`，不加 `/v1`）。需搭配支持 GPU 联动接口的新版 Qwen Launcher。设置保存在 ComfyUI 的 `user/yton-launcher.json`；插件默认关闭，本机部署时可开启。

- 对所有工作流生效，包括 API 提交；无需添加节点。只在实际出队执行前触发，提交队列与参数校验阶段不会卸载模型。
- 执行前立即暂停模型调度、中断正在生成或加载的模型，确认进程退出后才执行第一个节点。本地推理不会从中断处续写，请在工作流结束后重新请求。
- 执行期间后台续期占用许可，防止其他 Agent 请求或手动启动重新加载模型；新请求返回 503，已开始的流式请求收到错误事件。
- 结束、失败或取消时先卸载 ComfyUI 管理的模型并清理 CUDA 缓存，再释放占用许可。启动器保留上次预设，下次模型请求自动加载，不在工作流结束时立即加载。
- 开启联动但启动器不可达、版本不支持或卸载失败时，该工作流报错且不执行，后续队列仍可处理。可启动新版启动器或关闭联动恢复普通使用。
- ComfyUI 异常退出后，许可停止续期并在最多 90 秒后过期。已取得的许可可跨启动器重启恢复。工作流内部不应再调用同一个本地模型生成提示词，否则会被正在生效的 GPU 占用保护拒绝；应先生成提示词，再运行工作流。

后端在 ComfyUI 的 `PromptExecutor.execute` 外包一层执行保护，不修改 ComfyUI 核心文件。当前执行入口改变时需重新适配。此功能会清除 ComfyUI 模型显存常驻缓存，连续工作流可能重新加载模型。
