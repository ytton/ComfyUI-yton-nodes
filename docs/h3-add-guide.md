# 关键帧替换与 Add Guide

在【人物替换配置器 · 配置输出】的视频上方点击“关键帧替换”，预览当前段裁剪、压缩后的视频。拖动缩略图条定位，左右方向键逐帧移动，空格播放或暂停，按 C 收集当前帧。

替换帧以双列卡片展示，每张卡片并排显示原帧与替换图；对应编号标记显示在时间轴上。拖动标记或修改卡片中的帧号可调整位置。原帧以“原视频名_第N帧.png”下载，帧号与弹窗一致。下载原帧进行编辑，再点击或拖入替换图片。选帧与上传自动保存，关闭后可继续编辑。未上传替换图的选帧不会参与生成。调整已上传帧的位置后，卡片提示重新上传对应图片，原替换图暂停参与生成，直至上传新图。改变源文件、分段、裁剪或压缩设置后，使用对应处理版本的独立选帧记录。

将【人物替换配置解析器】末尾的“替换关键帧”输出连接到全模态生成节点 Add Guide 分组中的“关键帧”，开启“启用 Add Guide”。每张替换图分别调用官方 `MiniMaxH3AddGuide`，按选定位置注入，不需要填写帧号。内部帧位置从 0 开始，界面从第 1 帧显示；非 24fps 的片段按时间位置换算为 H3 的 24fps 帧轴。

循环生成会自动取当前段的关键帧。启用上下文且自动增加时长时，关键帧顺延 22 帧；输入片段已包含上下文、关闭自动增加时长时，保持片段原有帧位置。传统二采在两种分辨率分别编码同一组关键帧，TR 与 SelfLift 沿用相应条件。未收集或未上传关键帧时，按正常流程生成。
