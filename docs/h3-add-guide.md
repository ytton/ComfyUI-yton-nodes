# 全模态生成的 Add Guide

三个全模态生成节点都提供可选的 Add Guide 分组，默认关闭。开启后，使用 ComfyUI 官方 `MiniMaxH3AddGuide` 将画面或音频注入指定时间位置。

- **注入视频**：使用第一个有效视频，按原时长转换为 24fps，并带入原音轨。视频优先于注入图片。
- **注入图片 / 帧批次**：支持单张图片或视频帧批次，未提供注入视频时使用。
- **注入音频**：支持单独注入，也可替换注入视频自带的音轨。
- **注入位置 / 帧**：0 表示生成片段的第一帧，负数从末尾计数，包含分段上下文占用的帧。画面与音频共用起点。

注入不改变生成长度。官方 Add Guide 会把多帧画面向下取为 5、22、39…帧，不足 5 帧只用第一帧；起点与注入长度需要放得进生成片段。普通模式使用填写的时长；复刻模式优先使用第一个参考视频的时长，未连接参考视频时使用已启用的注入视频。

顶部的视频列表仍是 `<Video N>` 参考，Add Guide 分组是按帧定位的引导条件。使用 Character Swap LoRA 时，可把角色图连接到顶部图片列表，把原片段连接到注入视频，位置设为 0。Add Guide 不会自动把原视频加入 `<Video N>` 引用。

分段上下文和 Add Guide 分别生效。两者同时开启时，模型同时收到原视频引导和上一段尾部引导；重叠时间区间的条件会叠加。需要错开时，按包含上下文的生成时间轴安排注入位置与片段长度。

传统二采在首采和最终分辨率分别编码同一组引导；TR 的引导随放大条件进入二采；SelfLift 共用引导条件。关闭 Add Guide 时，不读取注入媒体。
