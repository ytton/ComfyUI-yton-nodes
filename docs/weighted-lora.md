# 权重 LoRA 加载器

在 `yton-nodes → 模型` 中添加。连接模型，点击「添加 LoRA」逐行选择文件；CLIP 可选。

- 每行左侧的 `FLOAT` 接口控制该行 LoRA 强度。接入浮点数或计算节点后显示「外部控制」；断开后使用原来的行内数值。
- 未连线时，点击数值编辑，或用左右箭头以 0.05 调整。允许负强度，0 表示不加载。
- 每行开关控制是否加载，右侧 × 删除该行；顶部按钮统一启用或关闭。
- 按显示顺序应用 LoRA。添加、删除其他行以及保存重载均保持现有强度连线与 LoRA 的对应关系。
- 接入 CLIP 时，同一行强度同时作用于模型与 CLIP；不接 CLIP 时仅修改模型。

复用 ComfyUI 原生 LoRA 加载器，读取 `models/loras`；不依赖 rgthree。输入数量遵循 ComfyUI Autogrow 的 100 项上限。

重启 ComfyUI 后刷新页面，搜索「权重 LoRA 加载器」。
