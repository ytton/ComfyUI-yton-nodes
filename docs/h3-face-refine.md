# H3 小脸修复

独立复用【H3 全模态生成】的小脸检测、跟踪、局部采样和拼回处理，方便接入其他工作流。

## 接线

```text
VAE 解码 / 加载视频拆出的图片帧 → H3 小脸修复 → 保存图片或创建视频
H3 ref2va MODEL              → 修脸模型
H3 CLIP                     → H3 CLIP
H3 视频 VAE                 → H3 视频 VAE
人物参考图 1                 → 参考图 1（可选）
人物参考图 2                 → 参考图 2（连接上一项后自动出现）
```

【提示词】可连接原提示词或填写局部修脸描述。参考图使用原生动态入口：连接参考图 1 后出现参考图 2，继续连接后依次增加，最多 9 项，与官方 H3 参考生成节点一致。每个入口使用该批次的第一张图；多个人物请分别连接不同入口，按有效入口顺序对应 `<Picture 1>`、`<Picture 2>` 等标签。所有参考图共同参与每个人脸的修复，人物对应关系由提示词描述，参考图编号不是检测人脸的序号。不传参考图时依据原画面和提示词修复。

输入是整段 IMAGE 图片帧批次，输出保持原始画布、帧数和顺序。音频继续接原流程，创建视频时沿用原 FPS；节点不重生成或输出音频，也不需要 AV latent 或音频 VAE。

修脸模型明确连接一个 H3 ref2va MODEL，可直接连接现有主模型输出（含 LoRA），也可以使用独立修脸模型。该节点仅使用 H3 修脸模型；其他视频模型生成的图片帧同样可以作为输入。

## 控制

- **启用修脸**：关闭时直接返回输入，不执行检测、CLIP 编码、VAE 编解码或采样；关闭时也可不接修脸模型、CLIP 和 VAE。
- **修脸人数**：按现有修脸逻辑逐个处理人脸，默认 1。
- **修脸 Sigma**：支持手填和 STRING / SIGMAS 连线；留空使用内部 4 步、denoise 0.4。连接时完全使用上游时间表。
- **倒序修脸**：先倒序进行跟踪和修复，再恢复原顺序输出。

其他参数与全模态节点一致：`face_yolov8m.pt`、ER-SDE、种子 42、最大 768 裁切画布、大脸降噪倍率 0.35，以及仅人脸区域拼回。没有额外暴露调度、检测或拼回参数。

依赖已安装的 `ComfyUI-H3-FaceRefine`、yton 参考生成节点及检测权重 `models/ultralytics/bbox/face_yolov8m.pt`。新增节点需要重启 ComfyUI 后端并刷新页面；菜单位于 **yton-nodes → MiniMax H3 → H3 小脸修复**。

CPU 测试验证 V3 展开、关闭旁路、多脸链路、Sigma 和现有全模态分支。浏览器检查节点创建、接线及保存重载；这些验证不替代 GPU 成片画质测试。
