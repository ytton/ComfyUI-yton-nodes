# llama.cpp 提示词优化器

在 `yton-nodes → 提示词` 添加 **llama.cpp 提示词优化器**。模型使用当前 ComfyUI Python 环境中安装的 `llama-cpp-python`，直接读取 `ComfyUI/models/LLM` 下的 GGUF，不启动额外服务。可与已安装 llama.cpp 节点共用模型文件。

填写用户提示词或系统提示词，按需选择多文件 Skill 和本地模型，将 STRING 输出连接到后续生成节点，运行工作流即执行增强。用户提示词、系统提示词支持连线；图片、音频、视频支持原生列表输入。关闭增强后，用户提示词原样直通，不读取 Skill、不处理素材、不加载模型。

节点右下角齿轮配置当前节点的上下文、输出长度、采样、思考预算、GPU 层数、CPU 线程、批次、Flash Attention、KV 精度和多模态投影模型。设置随工作流保存，取消不会生效。模型文件列表可用模型右侧刷新按钮更新，打开设置不会加载模型。

思考强度通过模型模板的思考开关与 Token 预算控制，实际效果取决于模型。思考和最终正文共用最大输出限制；选择强度时自动给正文留出输出空间。模型输出截断、只有思考或出现工具调用时会报错，避免把这些内容传给生图。

多模态模型需匹配的 mmproj。自动模式选择同目录唯一的 mmproj；多个投影文件需要手动指定。自动模板支持 Qwen3.5 / 3.8、Qwen3-VL 和通用 MTMD；纯文本 GGUF 使用文件内置的聊天模板。图片与视频画面需要视觉支持，音频和视频原音轨需要音频支持；例如 Qwen3.5 视觉模型不具备音频理解能力时会明确拒绝音轨输入。视频按现有素材处理逻辑抽取最多 12 帧，不作为完整时序视频直接解码。

默认执行结束释放模型，为后续生图腾出显存。开启“生成后保留模型”可加快重复增强，但会持续占用显存。修改采样和思考参数可以复用模型，修改加载参数会重载；取消或失败会释放模型。该节点与其他插件各自管理模型实例，不共享其已加载的权重。

Windows 下 llama.cpp 的 CUDA 后端需要与其编译版本匹配的运行库，与 PyTorch 的 CUDA 版本可能不同。选择 GPU 推理但后端无法加载时会明确报错；检查运行库依赖并重启 ComfyUI，或将 GPU 层数设为 0 使用 CPU。GPU 层数 -1 表示全部层，内部使用当前库的 `all` 参数。

OpenAI 优化器与本地优化器均只显示简短执行状态，结果通过 STRING 输出传给下游，节点内不展示大段结果。
