# 保存视频

分类：`yton-nodes/媒体`。接入【创建视频】的 `VIDEO`，或图片序列帧与可选音频。两个视频来源同时接入时优先使用 `VIDEO`；此时独立接入的音频会替换原音轨。

路径相对于 ComfyUI 的 `output`，包含目录与文件名前缀，例如 `视频/{date}/XX/片段-{index}`。点击路径下方的标签可在光标处插入日期、时间、序号、分辨率、帧率、帧数等；时间使用 Windows 可用的 `HH-mm-ss`。路径不必带扩展名。序号 0 表示自动递增，同名文件不会覆盖。

帧率 0 沿用视频帧率；图片序列使用 24 fps。修改视频帧率时重采样，保持视频时长。支持 MP4、MKV、WebM、MOV 与 H.264、AV1、ProRes；不匹配的编码自动调整并提示。

视频先编码到临时文件，成功后再发布到指定位置。指定目录失败时改存 `output/video/恢复/日期/时间/`；输出目录也不可写时保留临时文件。编码失败会尝试通用 MP4，写入失败还会依次尝试输出目录和系统临时目录。日志与节点显示实际保存路径和警告，成功登记的文件可在任务记录中预览。

如果最终仍无法保存，节点明确显示“未保存”，继续输出原视频。硬盘全满、全部位置不可写或无效媒体仍可能无法落盘；请根据日志处理并及时使用后续节点保存返回的视频。用户主动取消任务仍按 ComfyUI 的取消流程处理。
