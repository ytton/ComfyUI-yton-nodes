# 人物替换内置循环

配置器只输出一份“本段配置”。循环开启时，从面板选中的片段依次生成到末段；关闭时只生成选中的一段。

连接方式：

- 配置器“本段配置” → 配置解析器“本段配置”。解析器不再接收外部索引。
- 解析器的媒体、提示词与尺寸 → 全模态节点的对应输入。
- 解析器“上一段视频”“启用上下文” → 全模态节点的同名输入。
- 全模态“本段视频” → 循环视频保存“待保存视频”。片段序号、总数、项目目录由解析器提供。

保存器的“上一段视频”输出是本段已完成的生成结果，供下一轮使用。内置循环等待保存完成后，将它放入下一轮的配置；不要在画布上将保存器反向连接到当前生成节点，这会形成依赖环。无需添加官方循环开始或结束节点。

第一段的上一段视频为空，上下文自动关闭；后续段通过解析器的实际连线启用上下文。循环按保存顺序执行，全部片段到齐后合并。

重跑某一段：在配置器选中该段，关闭循环，并在保存器开启“覆盖最近项目中的本段”。系统读取同一项目的上一段作为上下文，只覆盖所选片段并重新合并。开启循环则从所选片段续跑到末段。最近项目中缺少本段时直接新增，找不到对应项目则创建新项目；没有上一段视频时关闭本段上下文。关闭覆盖会创建新项目。
