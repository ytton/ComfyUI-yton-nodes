# SelfLift 通用流：LoRA 整理版

工作流文件：`examples/MiniMax H3 SelfLift通用流-LoRA整理版.json`。

以用户的 `MiniMax+H3 SelfLift通用流.json` 为基础，将上方 LoRA 区域整理成四个「权重 LoRA 加载器」和两个模型选择节点：

| 武戏开关 | 低分阶段 | 高分阶段 |
| --- | --- | --- |
| 关闭 | 首采 · 普通 LoRA | 高分 · 普通 LoRA |
| 开启 | 首采 · 武戏 LoRA | 高分 · 武戏 LoRA |

每张列表包含对应阶段完整的 LoRA 配方，包括最后加载的 FL2V Turbo。选中列表后，按行顺序加载其中开启的项目。每行左侧接口可通过连线单独控制强度，行右键支持排序。新增或替换 LoRA 时，长列表使用 ComfyUI 原生搜索框，按文件名或目录名过滤，支持方向键和 Enter 选择。

源文件当前关闭武戏、开启上下文；整理版沿用这些状态。武戏列表中的人物替换和 DMAD 即使已勾选，也只有武戏总开关开启后才会参与生成。上下文仍独立控制上一段视频引导、裁帧和颜色对齐。

整理版保留各行的勾选、顺序和强度，以及原采样、上下文、媒体和输出参数。将源文件漏接的高分武戏加载器接到同一基础模型，两个阶段独立加载各自的 LoRA。节点总数从 87 个减少到 80 个，连线从 110 条减少到 102 条。

验证包括：四种开关组合的采样与输出依赖对照、原生 LoRA 加载器展开、启用模型文件检查，以及独立浏览器中的导入、保存重开、强度连线和模型路由。对照以补齐源文件缺失的基础模型连接为前提；本次未运行视频生成。
