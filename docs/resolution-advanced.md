# 分辨率比例控件 · 高级版

在 `yton-nodes/分辨率` 中添加 **分辨率比例控件 · 高级版**（`YtonResolutionSelectorAdvanced`）。原版和 simple 版仍可独立使用。

MiniMax H3 模式提供 320p～1080p 的九个预设；普通 / 图片模式提供 2K、2.5K、4K、6K 等更高分辨率。

右下角齿轮提供三个设置页：

- **输入 / 输出**：分别控制宽度、高度、比例、分辨率四个输入，以及宽高、比例、长边、短边、H3 倍率、分辨率名称七个输出。已接线的端口需要先断开才能隐藏。
- **区域**：分别显示或隐藏模式切换、分辨率区域、比例区域和自定义宽高区域。区域显示与接线端口互不影响。例如关闭比例区域，保留比例输入，即可完全跟随上游比例。
- **预设选项**：控制各个分辨率和比例按钮。两种模式分别保存。每类至少保留一个选项；整个区域通过“区域”页关闭。

默认显示比例输入和全部输出。隐藏的参数保留当前值，仍参与计算；连接输入后优先使用上游值，对应按钮或数字框不可编辑。

宽高均为 0 时按分辨率、比例预设计算。只输入宽度或高度时，另一边按比例计算；两边均大于 0 时按指定尺寸计算。H3 尺寸向下对齐到 32 的倍数，最小为 32。指定宽高后的比例输出反映最终尺寸。

端口仅改变可见性，输出顺序和 API 索引固定。隐藏中间输出不会导致后续接线取错值。设置随工作流保存，复制节点也会保留。

更新插件后重启 ComfyUI、刷新网页，再搜索高级版节点。

验证：`python -m unittest discover -s tests -p "test_resolution*.py" -v`。
