# H3 全模态生成 · 视频上下文

`YtonH3VideoContextOmniGenerate` 支持独立的全模态生成，“上一段视频”为可选输入。“分段上下文”中的“启用上下文”默认关闭；关闭时即使接入上一段视频，也不会提取尾帧、增加或裁除上下文帧、匹配上一段颜色。未接上一段视频时按独立片段生成。

需要接续时，打开“启用上下文”，并把“上一段视频”接入上段成片：可以直接连接前一个生成节点的“本段视频”，也可以通过“加载视频”读取已有视频。

节点内部按以下顺序处理接续：

1. 取上一段视频的尾部 22 帧及对应音频。
2. 前 21 帧添加 0.1 噪声，最后一帧保持原样。
3. 画面与音频通过 `MiniMaxH3AddGuide` 锚定在本段第 0 帧，再以 `MiniMaxH3AudioGuideFeather` 设置 256 ticks 的音频羽化。
4. 自动补足生成帧数，输出时裁掉头部 22 帧和尾部 H3 帧格补齐部分。音频同步裁切，得到填写时长的本段视频。
5. 按原流使用 `ColorTransfer(mkl_lab, target_frame=0, strength=0.75)`，以刚才上一段视频的最后一帧对齐本段颜色。

图片、视频、音频保持普通参考输入；“视频”用于当前源素材，“上一段视频”用于接续。单采、二采、首采比例、Sigma、小脸修复及主模型、二采模型、修脸模型接口沿用 H3 全模态节点。

素材输入按实际内容判断：媒体加载器即使已经连线，未上传或全部禁用的素材也会跳过。普通模式下，只上传图片时走图生视频；所有素材为空时走文生视频。关闭上下文时不会读取上一段视频。

普通模式可接完整源视频，按序号和时长自动截段；复刻模式接当前已裁好的源视频片段，时长自动推算。接续时两种模式都自动处理额外的 22 帧。

示例工作流：`examples/H3_全模态生成_单采二采_分段修脸_视频上下文.json`。

包内菜单统一为“分辨率、逻辑、媒体、MiniMax H3、提示词”。规划、裁切、上下文存取、工作台适配和上游节点别名保留执行注册，标记为内部节点，默认从创建菜单与搜索中隐藏。
