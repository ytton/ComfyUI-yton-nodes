# H3 全模态生成：共用视频上下文

TR、SelfLift 和传统二采三个节点都支持独立的全模态生成，“上一段视频”为可选输入。“分段上下文”中的“启用上下文”默认关闭；关闭时即使接入上一段视频，也不会提取尾帧、增加或裁除上下文帧、匹配上一段颜色。未接上一段视频时按独立片段生成。

需要接续时，打开“启用上下文”，并把“上一段视频”接入上段成片：可以直接连接前一个生成节点的“本段视频”，也可以通过“加载视频”读取已有视频。

节点内部按以下顺序处理接续：

1. 取上一段视频的尾部 22 帧及对应音频。
2. 前 21 帧添加 0.1 噪声，最后一帧保持原样。
3. 画面与音频通过 `MiniMaxH3AddGuide` 锚定在本段第 0 帧，再以 `MiniMaxH3AudioGuideFeather` 设置 256 ticks 的音频羽化。
4. 自动补足生成帧数，输出时裁掉头部 22 帧和尾部 H3 帧格补齐部分。音频同步裁切，得到填写时长的本段视频。
5. 按原流使用 `ColorTransfer(mkl_lab, target_frame=0, strength=0.75)`，以刚才上一段视频的最后一帧对齐本段颜色。

图片、视频、音频保持普通参考输入；“视频”用于当前源素材，“上一段视频”用于接续。支持单采、升分辨率采样、Sigma、小脸修复及主模型、二采模型、修脸模型输入。

素材输入按实际内容判断：媒体加载器即使已经连线，未上传或全部禁用的素材也会跳过。普通模式下，只上传图片时走图生视频；所有素材为空时走文生视频。关闭上下文时不会读取上一段视频。

## 三种升分辨率方案

上下文、声画裁切和颜色处理由三个节点共用。TR 固定 Film 2×；SelfLift 在同一条 Euler 时间表中途升分辨率；传统二采使用 3D latent 超分后独立采样。每个节点只显示自身方案的参数，选择单采后收起整个二采区。

TR 将首采参考条件随 latent 一起放大；传统版在目标尺寸重新编码原提示词及参考，并再次注入上一段上下文；SelfLift 接收目标分辨率条件，由原生渐进采样器处理低分与高分阶段。

三个节点的小脸修复都只保留启用、人数、Sigma、倒序。Sigma 留空使用内部 4 步、降噪 0.4；关闭修脸时不执行该分支。
