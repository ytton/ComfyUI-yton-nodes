# OLDX 人物遮罩局部替换

导入 [遮罩版工作流](../examples/OLDX_personswap_ComfyUI-遮罩局部替换.json)。这是对 `OLDX_personswap_ComfyUI` 的局部替换改版，使用 Qwen Image 2.1、原人物替换 LoRA 和原采样配置。

1. 在「参考角色 · 图1」加载要换成的角色，在「原场景」加载需要编辑的完整图片。
2. 右键原场景节点，打开遮罩编辑器，涂选目标人物并保存。白色区域会替换，黑色区域保留；避开其他人物。遮罩应覆盖原人物及新发型、服装需要占据的空间。
3. 运行后检查「实际送入 Qwen 的局部图」：应只看见选中的人物，未选区域为灰色。角色参考与这张局部图也会一起送给提示词优化器，优化结果连接到实际生成提示词。
4. 生成结果自动缩回裁剪区域的原尺寸，按原遮罩贴回。最终保存的是原尺寸完整图片，位置在 `output/OLDX/遮罩局部替换/`。

裁剪框内的未选区域也会填灰，避免附近另一人进入 Qwen；回贴时仅修改遮罩内像素。边缘融合默认关闭，如需扩大衣服或头发轮廓，应先扩大遮罩。未绘制有效遮罩时无法完成指定人物替换，请先检查遮罩预览。

一次处理一人。替换第二人时，把第一次保存的完整图片作为原场景，再为第二人绘制遮罩。

依赖已安装的 `ComfyUI-Inpaint-CropAndStitch`，以及原工作流的 LayerStyle、WAS Node Suite、rgthree、EasyUse 和 yton-nodes。导入其他机器后需重新选择角色、场景、模型、LoRA 及本地提示词优化器配置。
