# H3 模块实验工作流

把「H3 全模态生成」的处理链展开为 ComfyUI **原生子图**。双击模块可以看到、修改和复制实际节点；主流程没有调用整合生成节点。

## 导入与开始

- `examples/H3_模块实验_3D-LMS.json`：Easy Media 的 3D 潜空间超分，可选择原版或 LMS 权重。
- `examples/H3_模块实验_Film2x.json`：使用 `h3_clean_latent_upscaler_film_epoch200.safetensors`，固定 2×，通过 Combined 节点处理 FP32 模型和重新加噪。

把 JSON 拖入 ComfyUI，或通过工作流菜单打开。两份都是独立工作流，另存文件实验即可。原有示例不受影响。

主画布的 **00 参数与功能开关**直接提供宽高、时长、种子、二采、上下文、复刻、修脸、调色和源视频片段序号。默认 5 秒、1344×768、固定种子 42，开启二采，关闭上下文和修脸。宽高按 64 像素对齐，二采首采为目标的一半；例如填 1280×720，实际目标为 1280×704。对齐后的实际宽高也在参数模块的输出端显示。

「当前素材」的图片、视频、音频都可以留空；留空是文生视频，只提供图片是图生视频。正常使用时修改生成提示词；图片按 `<Picture N>`、视频按 `<Video N>`、音频按 `<Audio N>` 引用。

「上一段成片」仅填写第一个视频，并打开上下文开关才参与生成。输出是新片段，前一段的 22 帧只作引导，最后会裁掉。也可以把另一条生成链的 VIDEO 输出接到 **02 时长与素材判断**的「上段视频」入口。

## 模块划分

| 模块 | 可直接实验的内容 |
| --- | --- |
| 00 参数与功能开关 | 目标尺寸、可见时长、固定种子、功能开关 |
| 01 模型与 LoRA | 主模型、编码器、双 VAE、注意力、Shift、首采与二采 LoRA |
| 02 时长与素材判断 | 空视频判断、普通／复刻模式、H3 帧格、22 帧增量 |
| 02a 源视频切片 | 普通模式的视频分段与声音裁切；源视频须为 24fps |
| 02b 上段尾部 22 帧 | 前 21 帧加噪 0.1，最后一帧保持原样，同步提取音频 |
| 03 首采参考与引导 | 多模态参考编码、源视频引导、上一段引导、音频羽化 |
| 04 首次采样 | 调度器、噪声、Guider、采样器、干净 latent 输出 |
| 05 超分与二采准备 | 超分模型、二采条件、Sigma、噪声策略 |
| 06 第二次采样与单采开关 | 二采采样器、采样与视频解码；单采时跳过二采链 |
| 07 小脸精修 | 人脸追踪、局部编码、逐帧降噪、局部采样、贴回 |
| 08 裁切与色彩匹配 | 裁掉上下文与帧格余量、可选色彩匹配、合成当前成片 |

普通模式使用填写时长；存在源视频时按「第几段」截取首个源视频。复刻模式使用第一个源视频的实际时长，保留传入的视频参考列表，填写时长和片段序号不参与规划；复刻模式必须提供视频。普通模式的源切片只使用第一个视频。

7.5 秒为 180 个可见帧。接续时加上 22 帧后，再补至 H3 的 `17k+5` 帧格，实际采样 209 帧；输出裁掉头部 22 帧、尾部 7 帧，保留 180 帧。

## 更换超分模块

先双击 **05**。3D 版可直接在 `easy minimaxH3LatentUpscaler` 选择原版或 `h3_upscaler_lms_v0.1.safetensors`；默认 2×，开启时序分块，超分结束后卸载其权重。

两版 05 的输入名称、类型、顺序一致，输出统一为 `latent / noise / sigmas / guider`。从另一份工作流复制 05 子图，按同名入口重接，即可保留其余阶段做对照。

**四条输出要成套连接到二采**：

- 3D／LMS 输出干净的放大 latent，二采使用 RandomNoise 加噪。
- Film Combined 已按同一条 Sigma 给视频重新加噪，二采必须接其 DisableNoise 输出；`audio_denoise=0` 锁住首采音频。
- Film 的条件在目标尺寸重新编码；不要再把该条件送进 Combined 的 positive，否则会重复放大条件尺寸。
- Film 默认二采 Sigma 为 `0.35, 0.175, 0`；3D／LMS 默认 `0.631578922, 0.3158, 0`。这两份模板便于验证接法；要严格比较模型效果，应自行统一适用的采样设置。

若想实验非 2× 的 3D／LMS 超分，在 02 中调整首采宽高公式，同时把超分尺寸和 03／05 的编码尺寸一起对应修改。Film 只能保持精确 2×。

## 其他常用实验

- 首采／修脸改用自定义 Sigma：替换对应 BasicScheduler，并重接采样器的 sigmas；此后强度由 Sigma 曲线决定。
- 颜色对照：使用主画布的调色开关，或展开 08 更换 ColorTransfer。现有配置是匹配上一段尾帧的单一变换，强度 0.75；它不保证任意长接续都没有亮度漂移。
- 增加精修人物：复制 07，把前一个 07 的画面输出接到后一个 07 的底图入口，共用原始音频 latent；在新模块里把人脸 `select_index` 改为下一个序号。参考图和提示词可分别更改。
- 暂时关闭修脸／上下文／二采：使用主画布开关，未选分支通过 lazy ifElse 跳过。

## 依赖与验证

使用本机已经安装的 ComfyUI 原生子图、FastUse、KJNodes、Easy-Use、Easy-Media、H3 FaceRefine、H3 Audio Guide Feather 和本插件；Film 版另需 ComfyUI-MiniMaxH3_LatentUpscaler。模型与 LoRA 使用原示例中的本地文件选择，可在 01 中更改；人物替换 LoRA 默认强度为 0。

已在本机 ComfyUI 检查两份 JSON 的导入、原生子图展开、参数表面编辑、实际 API 导出、必填输入与模型选项。离线测试逐线核对交付工作流，并覆盖空素材、惰性分支、7.5 秒补帧、复刻时长、2× 尺寸及 Film 噪声连接。尚未运行完整 GPU 生成，出片质量和耗时需实际短片验证。

```powershell
python -m unittest discover -s tests -p test_h3_modular_workflows.py -v
```

维护时先运行 `python tools/build_h3_modular_spec.py` 产生规格，再将生成的 JSON 替换到 `tools/build_h3_modular.browser.js` 的 `__H3_MODULAR_SPECS__` 标记，通过独立 ComfyUI 页面的 Playwright 函数生成原生子图。该函数返回两份 workflow、平铺图和 API 图，由调用者保存；生成过程不会提交任务。
