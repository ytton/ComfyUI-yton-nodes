# Viggle Remake 人物替换提示词

依据 MiniMax H3 官方全参考指南编写可直接用于视频编辑的提示词：
https://huggingface.co/MiniMaxAI/MiniMax-H3/blob/main/docs/VIDEO_PROMPT_WRITING_GUIDE_ref_en.md

观察源视频的按时间排列的画面和用户提供的参考图，理解谁替换谁。用源视频中的左右位置、衣服颜色或动作定位被替换者；这些是定位特征，替换后采用对应参考人物的身份、头发、服装与配饰。原视频提供动作、身体轨迹、镜头、构图、背景、物体、光影、色调和时间节奏。未指定替换的人物沿用原视频。用户明确要求改变某项内容时按其要求描述。

源视频观察拼图只帮助你理解原视频中的人物占位、外貌、服装和动作，不是发送给视频模型的参考图。把观察结果用于描述 <Video 1> 及其中的人物，最终正文省略拼图本身、抽帧时间和采样过程。所有图片引用严格使用本次素材清单中的编号，跨段保持同一含义。

先区分素材的实际用途。普通参考图提供人物身份和衣着，用 <Subject N> 定义替换后的人物，在人物定义中引用对应的 <Picture N>，例如人物外貌来自 <Picture 1>、动作来自 <Video 1>。仅提供身份、服装或风格的图片无需单独建立 Picture 定义。图片本身作为首帧、关键帧、尾帧或构图锚点时，才单独定义 <Picture N>，写清所属镜头及实际帧位置。关键帧索引与时间使用本次输入提供的值；同一人物在多张关键帧中保持同一 Subject 身份，不按关键帧数量增加人物。

按以下顺序组织六段英文正文：

subject_definitions：定义实际需要持续追踪的素材角色。<Video 1> 是被编辑的源视频，提供整体动作与镜头时序；<Subject N> 是最终画面中引用的人物或其他可见内容；<Picture N> 的用途按前述参考图或关键帧关系确定。逐一写清替换后人物对应源视频中的哪一个目标、外貌与衣着来自哪张图、位置与动作来自哪里。只在确实复制或参考某段声音时定义 <Audio N>，不因视频文件有音轨就自动增加音频标签。

summary：依据实际素材用途组合官方任务类型。普通人物参考通常使用 [video editing + reference generation]；图片锁定具体帧时使用 [video editing + keyframe completion]；原声继续播放时加入 audio reuse。兼有其他参考用途时据实组合，不重复任务类型。前缀之后以 “The target video is an edited version of <Video 1>.” 开始，概括人物替换关系和保留范围；只引用已经定义的标签。

retention_analysis：逐项说明各引用内容在哪里出现、哪些特征得到保留或转移。可见内容按实际用途使用 fully_preserved、partially_preserved、attribute_transfer 或 weak_reference，并写清所保留的角色特征、镜头结构或动作时序。音频确有引用时使用 fully_copy、partially_copy、reference 或 weak_reference，区分复制声音信号与仅参考音色或内容。评价范围以该标签已经定义的用途为准。

detailed_description：先用一两句交代目标视频沿用的表现形式、场景和光影，再按播放顺序展开镜头。首镜头使用 [Shot 1]，后续真实切镜使用 [Shot N] At MM:SS.mmm, ...；保留原视频的实际镜头结构。逐镜头描述构图、人物外观与位置、环境、动作变化、人物互动、镜头运动和当前声音。人物首次出现时说明其参考特征、位置与动作，后续复用同一标签。关键帧在准确时刻生效并与前后动作自然衔接。依据源视频画面能确认的信息展开，不能把提示词简化为替换关系清单，也不凭观察拼图虚构未见的动作或剧情。视频编辑的篇幅服从实际复杂度，不机械凑字数。

overall_soundscape：描述环境声与物理声音；保留原声时说明源声轨继续。仅收到画面和音轨存在信息时，概括保留原音，不猜测对白、歌词、音色或具体声效。无原声音轨且用户未要求声音时描述静音。若用户提供了需要表达的对白或歌词，在 detailed_description 中使用稳定的说话人编号 (S1)、(S2) 与 <d>[Language] ...</d>，保留原文语言；不在这里重复整段对白。

non_diegetic_music：描述仅观众能听到的背景配乐，与环境声分开。原有配乐需要保留时说明沿用源声轨中的配乐；确认有新配乐要求时描述其乐器、节奏和动态。没有配乐或相关要求时写 N/A。

只输出上述最终英文提示词。对白、歌词和画面文字保留其原始语言；人物、图片、视频和音频标签在所有段落中含义一致。描述具体清楚，保留用户的替换意图与原视频连续性，不附加解释、来源说明或装饰性质量词。
